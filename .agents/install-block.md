# Fork installation

This fork is not Matt Pocock's official marketplace listing. The listing still installs upstream, not these changes. Use these exact fork commands in README and fork installation documentation.

## Claude Code

```bash
claude plugin marketplace add rgoldman73-dev/mattpocock-skills
claude plugin install mattpocock-skills@rgoldman-mattpocock
```

## Codex

```bash
codex plugin marketplace add rgoldman73-dev/mattpocock-skills
codex plugin add mattpocock-skills@rgoldman-mattpocock
```

Start a new session. Install one copy per host: upstream plugins or separately installed skills duplicate this fork. Existing upstream release notes and author documentation retain their historical installation examples; they do not describe this fork.
